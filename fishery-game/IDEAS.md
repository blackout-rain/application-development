## おすすめの順番
1. **A1 注文** → 2. **C1 実績** → 3. **A2 加工場** → 4. **B1 季節・天候** → 5. **B2 釣り大会**

## 実装メモ（引き継ぎ用）
- ゲーム本体は `index.html` 1ファイル。バランス調整は `dev/tune.mjs`＋`dev/balance/`、自動プレイは `dev/run-bot.mjs`。
- 毎回: 回帰テスト → ボット（腕前 good/avg/poor）→ `node dev/check-prod.mjs` → 本番／管理者版の公開。
- 目標: 沖合の解放 1〜3日 / 全海域の解放 45〜60日 / 漁業王 70〜90日 / 所持金は数日分の日収。
- 保存データは `migrate()` で補完。新しい状態は `fresh()` に既定値を足す。

## 機能の段階解放（実装済み）
`FEATS`（index.html）に、解放条件を一覧にしてある。条件はレベル・ランク・船（海域）・主の討伐。
新しい機能を足すときは、`FEATS` に1行足して、画面側を `feat('キー')` で囲む。解放済みは `G.fu` に保存される。

## クリア後の遊び：のれん分け（周回）と伝説の主（実装済み）
- **解放**：ランク「漁業王」で、街タブに「のれん分け」が出る（`FEATS.noren`）。
- **のれん分け**：財産（お金・船・設備・従業員・養殖・研究・支店・借入・魚箱・ランク）を手放し、1日目から再開。のこるのは、図鑑・実績・主の記録・コンプ・レベルとステータス・BP・券・ペット・模様替え・のれんの強化（`NR_KEEP`）。実行前の状態は「控え」に自動で残る。
- **のれん**：もらえる数 = 12 + 売上÷1億 + 早さボーナス（600日より早い分、20日ごとに+1）。使い道は永続の強化5種（売値+4%・経験値+4%・はじめの資金¥3万・魚箱+2・色違い+20%、`NR`）。
- **周回の難しさ**：周回ごとに魚の引きが+6%（10周で頭打ち、`lapDiff`）。
- **伝説の主**：主を倒して、コンプした海域に出る（主の出現のうち半分）。引きが1.5倍。海域ごとに1周に1体、倒すと祝い金×3・BP×2・評判+5・のれん+4。記録は `G.leg`（累計）と `G.legLap`（今周）。
- 実績：のれん分け／老舗の主人（3回）／伝説に挑む者／伝説の覇者。
- 検証：`dev/qa.mjs` に7件、不変条件（`dev/admin.js`）に のれん・伝説の主 を追加。
- 周回の目安（ボット2回）：1周目 漁業王まで353・362日、2周目（のれん24〜28を売値Lv3に使用）298・301日。2周目はおよそ1周目の8割の長さ。強化を貯めるほど短くなる。

## 英語対応（実装済み）
- 日本語／English を設定タブで切り替え（端末の言語で自動判定）。文章は `T()`、英訳は `EN`、魚名は `NAMES`。詳しくは `dev/README.md` の「多言語」。
- 翻訳は、翻訳→逆翻訳つきの校閲→対訳表で依頼者が確認、の順で品質を確かめた。
- 未対応：ストア掲載文・プライバシーポリシーの英語版、Androidのアプリ名の言語別表示（`res/values-ja/strings.xml`）。

## ステータスの効果の調整（実装済み）
- 変更前：体力・器用さ・集中力は、24〜29ポイント（Lv12ごろ）で上限に達し、あとのBPがむだになった。一方、力は上限なしで400%以上まで伸び、商才・統率力は100ポイントまで伸びる、と効き方の幅がバラバラだった。
- いま：効果はすべて「最大 × v ÷ (v＋h)」の形（`js/core/stat-effects.js` の `STAT_FX`）。上限で止まらず、伸びだけが少しずつゆるやかになる。h（最大の半分になるポイント）は、戦闘系が46、経済系が70。
- 数値の決めかた：自動プレイ（旧い式）の実測のステータス（`dev/balance/stat-states.json`）で、各海域の主との勝率が旧い式とほぼ同じになるよう、`dev/stat-sim.mjs` で確認しながらフィットした。漁業王までの日数は、旧353・362・367日→新365・364・368日で変わらない。
- 調整するとき：`STAT_FX` の数字を変え、`node dev/stat-sim.mjs`（勝率）と、自動プレイのペース確認を行う。
