# ストア申請チェックリスト（Google Play・初回）

※ 条件や名称は変わることがあります。必ずPlay Consoleの最新の案内を確認してください。

## A. 準備（本人が行う作業）
- [ ] Google Play デベロッパーアカウントの登録（登録料 約25ドル・1回きり）
- [ ] 個人アカウントの場合、製品版の公開前に、クローズドテスト（テスターを集めて一定期間）が必要になることがあります
- [ ] Firebaseプロジェクトの作成（README の手順 1〜3）

## B. アプリに必要なもの
- [ ] アプリ名、短い説明（80文字）、詳しい説明（4000文字以内）
- [ ] アイコン 512×512 / 機能グラフィック 1024×500 / スクリーンショット（スマホ用 2枚以上）
- [ ] パッケージ名を決める（`capacitor.config.json` の `appId`。公開後は変更できません）
- [ ] 署名付きAAB（Android App Bundle）のビルド。Play App Signing を使う
- [ ] プライバシーポリシーのURL（`public/privacy.html` を、Firebase Hosting で公開 → `https://プロジェクトID.web.app/privacy`）
- [ ] アカウント削除のURL（`public/delete-account.html` → `https://プロジェクトID.web.app/delete-account`）

## C. Play Console の申告（下書き）
**データセーフティ**
| 項目 | 回答の目安 |
|---|---|
| データの収集 | あり（ログインした場合のみ） |
| 収集するデータ | 個人情報：メールアドレス、ユーザーID／アプリのアクティビティ：ゲームの進行データ |
| 目的 | アプリの機能（データの保存・引き継ぎ）、アカウント管理 |
| 第三者との共有 | なし（Firebaseは、サービス提供のための委託先） |
| 転送中の暗号化 | はい（HTTPS） |
| データ削除のリクエスト | はい（アプリ内の削除機能 ＋ 削除用URL） |

**そのほか**
- [ ] コンテンツのレーティング（質問票に回答。暴力・課金・ギャンブル要素などは「なし」）
- [ ] 広告：含まない
- [ ] 対象年齢層
- [ ] アプリのアクセス権：ログインなしで遊べる（Googleログインは任意）と申告できます

## D. 動作確認（実機で）
- [ ] ログインなしで、最後まで遊べる
- [ ] Googleログイン → クラウドに保存される
- [ ] 別の端末（またはアンインストール後）で、同じGoogleアカウントにログイン → 「引き継ぎますか？」が出る
- [ ] ログアウト／アカウント削除ができる
- [ ] 機内モードでも、遊べる（ゲームは端末内に保存されるため）
- [ ] 画面を縦向きに固定している・文字サイズ（標準／大／特大）で崩れない

## E. iPhone版を出すとき（あとで）
- Apple Developer Program（年 約99ドル）が必要です
- Googleログインを出すアプリは、「Appleでサインイン」など、同等の選択肢を用意するよう求められることが多いです
- ネットのページを開くだけのアプリは審査で落ちやすいため、ゲームの中身をアプリに同梱している点を、審査メモに書いておくと安心です
